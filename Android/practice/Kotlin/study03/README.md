# TodoApp

Kotlin과 Jetpack Compose로 만든 할 일 관리 앱입니다.
안드로이드 개발을 배우면서 만든 학습용 프로젝트로, 화면 구성부터 서버 통신까지 직접 구현했습니다.

---

## 만든 이유

안드로이드 앱이 어떤 구조로 돌아가는지 직접 만들어보며 익히기 위해 시작했습니다.
같은 앱을 React Native로도 만들어 두 방식을 비교해볼 계획입니다.

---

## 기능

- 할 일 추가, 수정, 삭제
- 체크박스로 완료 표시
- 서버(외부 API)에서 할 일 목록 가져오기
- 완료율 통계 보기
- 다크 모드 자동 적용

---

## 화면

하단 탭으로 세 화면을 이동합니다.

| 화면 | 내용 |
|---|---|
| 홈 | 진행률과 요약 정보 |
| 할 일 | 목록 조회, 추가, 수정, 삭제 |
| 통계 | 완료율 그래프 |

*(스크린샷 추가 예정)*

---

## 사용 기술

| 기술 | 용도 |
|---|---|
| Kotlin | 개발 언어 |
| Jetpack Compose | 화면 만들기 (코드로 UI 작성) |
| Material 3 | 디자인 |
| Navigation Compose | 화면 이동 |
| ViewModel | 데이터와 로직 보관 |
| Retrofit + OkHttp | 서버와 HTTP 통신 |
| Coroutines | 통신을 기다리는 동안 화면이 멈추지 않게 처리 |

## 폴더 구조

```
com.juchan.todo
├─ MainActivity.kt          앱이 시작되는 곳
│
├─ data                     데이터를 다루는 부분
│  ├─ Todo.kt               할 일 하나의 모양 (id, 제목, 완료 여부)
│  ├─ TodoRepository.kt     데이터를 가져오는 창구
│  └─ remote
│     ├─ TodoApi.kt         서버에 어떤 요청을 보낼지 정의
│     └─ NetworkModule.kt   서버 주소 등 통신 설정
│
└─ ui                       화면을 다루는 부분
   ├─ TodoNavHost.kt        어떤 화면을 보여줄지 정하는 곳 (하단 탭 포함)
   ├─ theme                 색상, 글꼴, 다크 모드
   ├─ home/HomeScreen.kt    홈 화면
   ├─ stats/StatsScreen.kt  통계 화면
   └─ todo
      ├─ TodoViewModel.kt   할 일 데이터와 추가·수정·삭제 로직
      ├─ TodoScreen.kt      목록 화면
      └─ TodoEditScreen.kt  수정 화면
```

## 구조가 어떻게 돌아가는지

역할을 세 덩어리로 나눴습니다.

```
   화면 (Screen)
   보여주기만 함. 버튼이 눌리면 "눌렸다"고 위에 알림
        │  ▲
        ▼  │
   ViewModel
   할 일 데이터를 보관하고, 추가·수정·삭제를 실제로 수행
        │  ▲
        ▼  │
   Repository → 서버
   서버에서 데이터를 받아 앱에서 쓰는 형태로 변환
```

예를 들어 할 일을 추가하면 이렇게 진행됩니다.

```
입력창에 쓰고 + 버튼 클릭
  → 화면이 ViewModel에 "추가해줘"라고 요청
  → ViewModel이 목록에 새 할 일을 넣음
  → 목록이 바뀐 걸 Compose가 알아채고 화면을 자동으로 다시 그림
```

화면을 직접 새로 고치는 코드가 없습니다. **데이터가 바뀌면 화면이 알아서 따라 바뀌는 것**이 Jetpack Compose의 방식입니다.

세 화면이 같은 ViewModel을 쓰기 때문에, 할 일을 체크하면 홈의 진행률과 통계 숫자도 함께 바뀝니다.

### 서버에서 가져올 때

```
버튼 클릭
  → ViewModel이 Repository에 요청 (이때 로딩 표시 켜짐)
  → Repository가 Retrofit으로 서버에 GET 요청
  → 서버가 JSON으로 응답
  → JSON을 앱에서 쓰는 형태로 변환
  → 목록 갱신, 로딩 표시 꺼짐
```

통신이 실패하면 아래쪽에 오류 메시지가 잠깐 표시됩니다.

## 실행 방법

1. Android Studio에서 프로젝트를 엽니다.
2. Gradle 동기화가 끝날 때까지 기다립니다.
3. 기기나 에뮬레이터를 선택하고 Run(▶)을 누릅니다.

안드로이드 7.0(API 24) 이상에서 동작하며, 서버 불러오기 기능에는 인터넷 연결이 필요합니다.
사용한 API는 가입이나 키가 필요 없는 테스트용 공개 API인 [JSONPlaceholder](https://jsonplaceholder.typicode.com/)입니다.
